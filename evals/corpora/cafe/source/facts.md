# 事実リスト（2026-11-18 に、惑星ザーハードの店に書き換えた。数字・構成は元のまま、名前と言葉だけを置き換えた）

- オアシス珈琲は、アルカ市とその周辺で12店舗を運営している。エリアは居住区・発着場・岩山・遺跡の4つ。
- 創業は2011年4月（居住区）。2026年4月で創業満15年。
- 最初の店は居住区本店。2014年10月に発着場中央店、2018年6月に岩山広場店（岩山エリアの1号店）、2021年8月に遺跡テラス店（遺跡エリアの1号店）、2024年3月に12店舗目の遺跡発掘小屋店を開業した。
- 2016年9月にポイント会員制度「オアシスクラブ」を、2022年4月に公式アプリとモバイルオーダーを始めた。
- 看板商品は、深煎りの豆を3種類ブレンドした「オアシスブレンド」（略称 OB）。豆は3つの栽培ドーム産。
- 豆は居住区の自社工房（2019年4月に稼働開始）で焙煎し、週に2回、金曜日と土曜日の午前中に各店へ届ける。季節のブレンドは3か月ごとに年4回切り替わる。
- ラストオーダーは原則として閉店の30分前。ただし、遺跡発掘小屋店は閉店の15分前。
- モバイルオーダー（略称 MO）は公式アプリから事前に注文と支払いができる仕組みで、原則として全店で利用できる。ただし、居住区信号塔店では店内の通信環境の都合により利用できない。
- 駐車場は原則として設けていない。ただし、遺跡テラス店には10台分の専用駐車場がある。
- ペットの同伴は原則としてテラス席に限る。ただし、身体障害者補助犬は店内の席にも同伴できる。テイクアウト（略称 TO）は全店で利用できる。
- オアシスクラブ（略称 OC）は入会費も年会費も無料。会計100円（税込）ごとに1ポイント。有効期限は最後に利用した日から12か月。100ポイントごとにドリンク1杯の無料券と交換できる。
- 朝の開店が最も早いのは居住区市場前店で、6時30分（表では6:30〜18:00）。
- 定休日は原則として店舗ごとに週に1日。ただし、表で「なし」の店舗（居住区本店・発着場中央店・発着場西口店・遺跡テラス店の4店）は年中無休。
- 座席数が最も多いのは遺跡テラス店の76席（次いで居住区本店68席）。全店の合計は498席。座席数は店内席とテラス席の合計で、2026年4月1日時点。
- 日曜日が定休日の店舗は居住区市場前店と岩山学園前店。
- 営業時間は発着場中央店が7:00〜22:00（15時間）、遺跡テラス店が9:00〜20:00（11時間）。
- 毎年12月1日から12月25日まで、「帰還祭」限定のドリンクを全店で提供する。
- 資料には、飲み物の価格、電話番号は書かれていない。
- 惑星の厳しい環境に合わせて、すべての店舗に空気を整える設備がある（店内ではマスクなしで過ごせる）。この資料では、惑星の大気・酸素の数値には触れない（ザーハードの設定資料と、検索で競合しないようにするため）。
