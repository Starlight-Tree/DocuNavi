# ノートメモ リリースノート（4.1.2 から 4.21.0）

## 1. このリリースノートについて

本書は、ノートアプリ「ノートメモ」の 4.1.2、4.1.20、4.2.10、4.12.0、4.12.1、4.21.0 の 6 つの版の変更点をまとめたものです。

変更 ID は「CHG-」、不具合番号は「BUG-」で始まり、数字 4 桁が続きます。数字の並びが似ているものがあるので、番号は正確にご確認ください。

各版の「既知の問題」は、その版のリリース時点で、修正されていなかった不具合です。「修正された不具合」は、その版で直った不具合です。

## 2. 版番号の読み方と対象 OS

版番号は「メジャー.マイナー.パッチ」の形で、区切りごとに数字の大小で比べます。たとえば、4.12.0 は 4.2.10 より新しい版で、4.1.20 は 4.2.10 より古い版です。

また、4.21.0 は 4.12.1 より新しい版です。4.1.20 と 4.12.0 と 4.21.0 は、桁の違いで別の版になります。

次の表に、各版のリリース日と、対象 OS（iOS と Android）の最小版を示します。

| 版 | リリース日 | iOS の最小版 | Android の最小版 |
|---|---|---|---|
| 4.1.2 | 2025年2月12日 | iOS 15.0 | Android 9 |
| 4.1.20 | 2025年4月22日 | iOS 15.0 | Android 9 |
| 4.2.10 | 2025年7月8日 | iOS 15.4 | Android 10 |
| 4.12.0 | 2025年9月16日 | iOS 16.0 | Android 10 |
| 4.12.1 | 2025年10月2日 | iOS 16.0 | Android 10 |
| 4.21.0 | 2026年1月20日 | iOS 16.4 | Android 11 |

パソコン版の最小版は、4.2.10 までが Windows 10 1809 と macOS 12 です。4.12.0 と 4.12.1 は Windows 10 21H2 と macOS 13、4.21.0 は Windows 10 22H2 と macOS 14 です。

## 3. 版 4.1.2

4.1.2 は、2025年2月12日にリリースされました。対象 OS の最小版は、iOS 15.0 と Android 9 です。

CHG-1204 で、1 つのメモに付けられるタグの上限を示す設定キー tags.max_per_note の既定値を、50 から 100 に増やしました。

4.1.2 の既知の問題は BUG-1477 です。全角の英数字で検索すると、半角で書かれたメモが見つかりません。

## 4. 版 4.1.20

4.1.20 は、2025年4月22日にリリースされました。対象 OS の最小版は、4.1.2 と同じ iOS 15.0 と Android 9 です。

CHG-2014 で、添付ファイル 1 つの上限を示す設定キー attachment.max_mb の既定値を、10 から 20 に増やしました。

4.1.20 で修正された不具合は BUG-1477 です。全角の英数字でも、半角のメモを検索できるようになりました。

4.1.20 の既知の問題の 1 つは BUG-7713 です。iOS で共有リンクを開くと、白い画面のまま進みません。

もう 1 つの既知の問題は BUG-1744 です。Android で、ホーム画面のウィジェットが更新されません。

## 5. 版 4.2.10

4.2.10 は、2025年7月8日にリリースされました。対象 OS の最小版は、iOS 15.4 と Android 10 です。

CHG-2104 で、自動保存の間隔を示す設定キー editor.autosave_sec の既定値を、60 から 30 に短くしました。

4.2.10 で修正された不具合は BUG-7713 です。共有リンクを iOS で開いても、画面が表示されるようになりました。

4.2.10 の既知の問題は BUG-7731 です。表を貼り付けると、右端の列が欠けます。BUG-1744 も、この版では修正されていません。

## 6. 版 4.12.0

4.12.0 は、2025年9月16日にリリースされました。対象 OS の最小版は、iOS 16.0 と Android 10 です。

CHG-2041 で、設定キー attachment.max_mb の既定値を、20 から 50 に増やしました。CHG-2014 で決めた 20 より大きい値です。

CHG-2140 で、API の GET /v2/notes に指定できる limit の上限を、100 から 200 に増やしました。

4.12.0 で、API の /v1/notes を非推奨にしました。API のレート制限は、毎分 60 回です。

4.12.0 で修正された不具合は BUG-1744 です。Android のウィジェットが、更新されるようになりました。

4.12.0 の既知の問題は、BUG-7731 と BUG-7371 です。BUG-7371 は、ちょうど 50MB の添付ファイルが、アップロードに失敗する不具合です。

## 7. 版 4.12.1

4.12.1 は、2025年10月2日にリリースされた修正版です。対象 OS の最小版は、4.12.0 と同じ iOS 16.0 と Android 10 で、新しい変更 ID はありません。

4.12.1 で修正された不具合は BUG-7731 です。表を貼り付けても、右端の列が欠けなくなりました。

4.12.1 の既知の問題は BUG-7371 です。4.12.0 から引き続き、修正されていません。

## 8. 版 4.21.0

4.21.0 は、2026年1月20日にリリースされました。対象 OS の最小版は、iOS 16.4 と Android 11 です。

CHG-2401 で、同期の間隔を示す設定キー sync.interval_sec の既定値を、300 から 120 に短くしました。設定できる最小値も、60 から 30 に下げました。

CHG-2410 で、API の GET /v2/notes に指定できる limit の上限を、200 から 500 に増やしました。同時に、関数 listNotes() を新設し、関数 getNoteList() を非推奨にしました。

CHG-2411 で、API のレート制限を、毎分 60 回から毎分 120 回に増やしました。4.21.0 で、/v1/notes を廃止しました。

4.21.0 で修正された不具合は BUG-7371 です。ちょうど 50MB の添付ファイルも、アップロードできるようになりました。

4.21.0 の既知の問題は BUG-7317 です。Android 11 で、ダークモードを切り替えると、編集中のメモが閉じます。修正する版は未定です。

## 9. 設定キーの既定値

次の表に、4.21.0 時点の設定キーの既定値と、その値に変えた変更 ID を示します。

| 設定キー | 既定値 | 値を変えた変更 ID |
|---|---|---|
| tags.max_per_note | 100 | CHG-1204 |
| attachment.max_mb | 50 | CHG-2041 |
| editor.autosave_sec | 30 | CHG-2104 |
| sync.interval_sec | 120 | CHG-2401 |

設定キーの単位は、attachment.max_mb が MB、editor.autosave_sec と sync.interval_sec が秒です。

## 10. API の変更

API を呼ぶときは、リクエストのヘッダー X-NoteMemo-Key に API キーを入れます。GET /v2/notes の limit の上限は、4.2.10 までが 100、4.12.0 と 4.12.1 が 200、4.21.0 が 500 です。

関数 getNoteList() は、4.21.0 で非推奨になりました。代わりに、4.21.0 で新設した関数 listNotes() を使います。

/v1/notes は、4.12.0 で非推奨になり、4.21.0 で廃止されました。

## 11. 不具合の追跡

次の表に、各不具合を既知の問題とした版と、修正された版を示します。同じ不具合番号が、複数の版の既知の問題に載ることがあります。

| 不具合番号 | 内容 | 既知の問題とした版 | 修正された版 |
|---|---|---|---|
| BUG-1477 | 全角の英数字で検索すると、半角のメモが見つからない | 4.1.2 | 4.1.20 |
| BUG-7713 | iOS で共有リンクを開くと、白い画面のまま | 4.1.20 | 4.2.10 |
| BUG-1744 | Android のウィジェットが更新されない | 4.1.20、4.2.10 | 4.12.0 |
| BUG-7731 | 表を貼り付けると、右端の列が欠ける | 4.2.10、4.12.0 | 4.12.1 |
| BUG-7371 | ちょうど 50MB の添付ファイルがアップロードに失敗する | 4.12.0、4.12.1 | 4.21.0 |
| BUG-7317 | Android 11 でダークモードの切り替え時に、編集中のメモが閉じる | 4.21.0 | 未定 |

BUG-7731 と BUG-7371、BUG-7713 と BUG-7317 は、番号の数字が入れ替わっただけで、別の不具合です。
