# 機能一覧

利用者の操作ごとに、できること・条件・制限を並べた一覧です（リファレンス）。仕組みは [architecture.md](architecture.md)、API は [api.md](api.md)、設定は [configuration.md](configuration.md)。

- **確認の範囲（2026-11-15）:** コードと既存の文書から書いた。画面は実機では見ていない。本番での確認状況は各文書の「未確認」と [roadmap.md](roadmap.md) が正本。
- **印:** 条件の頭に **設定**（コードの既定と本番の設定が違うことがある）か **実験**（範囲や精度に限りがある）が付く行以外は、本番で使える。

| 機能 | できること | 条件・制限 | 詳細 |
|---|---|---|---|
| | **チャット** | | |
| 質問と回答 | 資料の内容を質問し、回答を逐次表示で読む。会話を続けられる | 1〜2000 文字。資料に無いことは LLM が「無い」と答える | [検索設計](search-design.md) |
| 出典 | 文末の `[n]` から、出典の資料とページを右パネルで開く | 確かめるのは番号と引用語句の実在まで。**文を出典が支持するかは確かめない** | [API](api.md) |
| 回答対象 | 入力欄のチップで、質問の範囲（対象）を選ぶ | 会話ごとに固定。権限の範囲は超えられない | [設定](configuration.md) |
| 資料の選択 | 資料一覧でチェックした資料だけで答えさせる | ターンごとの指定。0 件では送信できない | [API](api.md) |
| 追質問 | 「それ」「もっと」など短い質問を、前の話題で補って検索する | 補完は LLM の短い 1 回。精度は実 API で未確認 | [設定](configuration.md) |
| 質問の例 | 空の会話に例を、回答のあとに続きの質問を出す | 資料ごとの固定の質問。用意が無い資料には出ない | `followUps.ts` |
| 停止・再試行 | 生成の停止、回答のコピー、失敗後の再試行 | 送り直しても通らない失敗（422・409・403）に再試行は出ない | [API](api.md) |
| 会話の一覧 | 過去の会話を選んで続きから読む・削除する | ログイン時のみ。最新 50 件、本人の分だけ | [API](api.md) |
| 再開の出典 | 再開した回答にも出典が付く | 検索しなかった回答と、いま見えない資料に基づく回答には付かない | [API](api.md) |
| | **資料** | | |
| 資料一覧 | 検索・グループ・対象・種別で絞って見る。状態を確認する | 読み取り専用。分類の設定は運用者の SQL | [API](api.md) |
| 閲覧 | 抽出テキストと元の PDF を切り替えて読む | PDF は 20 MiB まで。表示の確認は PC のブラウザーだけ | [API](api.md) |
| 関係図 | 入寮規程の条文の参照関係と、変更の影響範囲を見る | **実験**。**入寮規程 1 資料だけ**。定義語は辞書の 4 語だけ | [API](api.md) |
| | **検索** | | |
| ベクトル検索 | 質問の埋め込みと pgvector で近いチャンクを探す | `ready` の PDF が対象。LLM に渡すのは上位 2 件が基本 | [検索設計](search-design.md) |
| 検索の重ね | BM25 との統合、語の一致での並べ直し、「第N条」の参照先の追加 | **設定**。コードの既定は 3 つとも on。本番の値は未確認 | [決定記録](decisions/README.md) |
| | **安全性** | | |
| ガードレール | 指示の上書きなどを拒否し、回答の漏洩を逐次検査する | ルールベース。インジェクションを完全には防がない | [ガード](guardrails.md) |
| ロール制御 | ロールごとに、見える資料グループを制限する | 本番は `enforce`。限定ロールでの動作は未確認。変更の反映に最大 60 秒 | [設定](configuration.md) |
| ログイン | Google ログイン。サーバーが JWT を検証する | 本番は必須。期限切れ後の更新は未確認 | [設定](configuration.md) |
| | **LLM** | | |
| ヘッジ | 遅い呼び出しに追加の試行を投げ、最初の成功を採る | トークンが増える | [設定](configuration.md) |
| 予備モデル | 主モデルの一時的な失敗で、別モデルを 1 回試す | **設定**。本番は有効。実際に切り替わった回は未確認 | [設定](configuration.md) |
| 有料キー | 無料キーが 429 のとき、有料キーで試す | **設定**。本物の 429 では未確認 | [設定](configuration.md) |
| エラー文 | 失敗を、例外の内容を含まない固定文で返す | 切断は失敗にせず、呼び出しを取り消す | [API](api.md) |
| | **画面** | | |
| サイドバー | 開閉と縮小表示。チャット・新しい会話・ナレッジへ移動 | 基準は PC（幅 1280px 前後） | — |
| テーマ | ライト・ダークの切り替え | — | — |
| モード表示 | `mock`（固定の返答）か `gemini` かを示す | モックは検索しない | — |
| | **運用** | | |
| 取り込み | R2 の PDF をチャンク化・埋め込みして DB へ | 同期は週 1 回（2026-11-11 から）。R2 通知の Job は停止中 | [計画](roadmap.md) |
| 履歴の掃除 | 古い会話履歴の削除 Job | 初回は 2026-11-22。結果は未確認 | [計画](roadmap.md) |
| バックアップ | `pg_dump` を R2 へ週 1 回 | 実データでの復元は未確認 | [バックアップ](pg-backup.md) |
| MCP 検索 | Claude Code から資料を検索 | 運用者専用（全グループ） | [MCP 設計](mcp-tool-design.md) |

## 提供していないこと

- PDF 以外の取り込み、画面からの資料の追加・編集・削除
- ロールの管理画面（運用者の SQL）
- 2 段組み PDF の読み順の組み直し

機能を足す・変えるときは、対応する行も更新する。
