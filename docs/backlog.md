# バックログ（画面・情報設計）

2026-10-18 の画面レビュー（1280px・390px、ライト・ダーク）と、情報設計（IA）のレビューで見つけた、まだ着手していない項目です。
中長期の拡張（DB・認証・デプロイ）は [roadmap.md](roadmap.md) にあります。ここは画面と、関係図・検索の見せ方だけを扱います。

優先度は、利用者が「死に角」や「手探り」になるかどうかで付けました。工数は測っていません。
外部の調査は二次情報（解説記事・講義資料）で、原典は読んでいません。

## 高

| 項目 | なぜ | 直し方の案 | 依存 |
|---|---|---|---|
| 画面に URL を持たせる | ルーターも `pushState` も無く、画面は `useState` だけで決まる。共有できず、「戻る」はアプリの外へ出て、再読み込みで資料の詳細や選んだ項に戻れない | 資料 ID・表示の切り替え（PDF / AI用テキスト / 関係図）・選んだ項を、URL のハッシュかクエリに持たせる | なし |
| 関係図の根拠から PDF のページへ飛ぶ | 関係図のパネルに「p.3」と出るが、リンクではない。根拠の確認が手探りになる | 「p.3」を押すと PDF に切り替え、`#page=3` で開く | PDF の表示は、切り替えても閉じない作りなので、ページ指定の渡し方を決める |
| 関係図が出ない資料の理由を示す | 入寮規程以外では、「関係図」ボタンが無言で無い。機能が壊れたと受け取られる | 対象外の資料に「関係図は入寮規程だけ」と一行出す（または一覧に印を付ける） | なし |

## 中

| 項目 | なぜ | 直し方の案 | 依存 |
|---|---|---|---|
| チャット回答の Markdown 表示 | 回答の箇条書き・表・太字が、記号のまま見える（本文は常にテキストとして描画している） | 小さな描画器で、HTML は通さない | 本文を HTML として解釈しない方針を保つ |
| 引用チップ → 該当チャンク・PDF ページへ | チャットの出典は、ファイル名と抜粋だけ。検索の戻り値が `(ファイル名, 本文)` で、ページを持たない | 検索の戻り値にページとチャンク ID を足し、出典から PDF の該当ページへ飛ぶ | 上の「URL」と「PDF のページ指定」 |
| 例題チップ | 空状態の例題が平文で、押せない | 押すと質問として送る | なし |
| 監査パネル | 出典・使われた文書を、まとめて見せる | 引用チップと一緒に検討する | 引用チップ |
| PDF パーサの「第2章 入寮第4条」連結 | 章の見出しと次の条が 1 行につながる。画面ではなくパーサの問題で、検索の質にも響く（入寮規程は 3 チャンクだけで、条がページで切れる） | 章の見出しと条番号を分離するルール、または抽出の段階で整理する | 直したら、取り込みと埋め込みをやり直す（実 API の課金が出るので、先に確認する） |
| 資料群・種別の見せ方 | 一覧は平らな 6 件。`storage/pdf/` の資料群（`cafe` `guides` `zahard`）が画面に出ない | 資料群か種別の列と、絞り込みを足す | DB に資料群の列があるかを先に確かめる |
| 用語の統一 | 「資料」「設定資料」「文書」が混在。「チャンク」「埋め込み済み」「ホップ」「起点」など開発者向けの語が前面にある | 「資料」に寄せ、開発者向けの語は詳細に移す | なし |
| 会話履歴の再表示 | 再読み込みすると、続きは送れるが、前の内容が見えない | 履歴の再表示か、会話の一覧 | 履歴は DB にあるが、読み出す API が無い |
| 「Gemini」バッジの扱い | 利用者には意味が無い（開発者向けの表示） | 一般の利用者には隠す、または設定へ移す | なし |

## 低

| 項目 | なぜ | 直し方の案 |
|---|---|---|
| スマホで行が押せると分かる手がかり | PC のホバーしか手がかりが無い | 行末に「›」を置く |
| 詳細「AI用テキスト」の既定表示 | チャンクの番号と埋め込みモデル名が、最初の画面に出る | メタ行を折りたたむ、または文言を和らげる |
| 390px の一覧カードの読み上げ | 表を `display: block` にしたので、読み上げで列の意味が弱い | メタ行を `dl` にするか、ラベル付きのグループにする |
| PDF の右端切れ（スマホ） | ブラウザー内蔵のビューアの表示。CSS では直せない | 既知の制限として扱う |
| 関係図（390px）の操作ボタン | ノードが隅にあると、ズームの操作が重なる | 操作を半透明にする、またはノードを避ける |
