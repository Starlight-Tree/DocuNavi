# バックログ（画面・情報設計）

2026-10-18 の画面レビュー（1280px・390px、ライト・ダーク）と、情報設計（IA）のレビューで見つけた、まだ着手していない項目です。
中長期の拡張（DB・認証・デプロイ）は [roadmap.md](roadmap.md) にあります。ここは画面と、関係図・検索の見せ方が中心です。末尾に、運用・基盤の判断待ちの項目も置きます。

優先度は、利用者が「死に角」や「手探り」になるかどうかで付けました。工数は測っていません。
外部の調査は二次情報（解説記事・講義資料）で、原典は読んでいません。

2026-11-20 に、実装済みの項目と、現在の方針（スマホ実機は想定しない。[ui-review.md](../.claude/rules/ui-review.md)）に合わなくなった項目を外した（外した行は Git の履歴にある）。
高・中・低の表で残した行のうち、同日にコードで確かめたのは、関係図の説明（高）、章と条の連結・用語の統一（中）。関係図の操作ボタン（低）は確かめていない。「判断待ち・既知の穴」の行は、行ごとに日付と根拠を書いた。「測ってから決める」の行は、この点検の対象にしていない。
